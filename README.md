Alunos: 
- João Paulo Moura Furtado

Aplicação web com três módulos: Análise Fundamentalista, Fronteira Eficiente de Markowitz e Playground de Backtesting.

## Requisitos

- Python 3.11 ou superior

## Como executar

### 1. Crie um ambiente virtual e instale as dependências

**Windows**
```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

**macOS / Linux**
```
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Inicie o servidor

```
python app.py
```

### 3. Acesse no navegador

```
http://localhost:5000
```

---

A instalação leva alguns minutos na primeira vez. As execuções seguintes são instantâneas.
